## 🕹️ Overview

DDrawCompat is a drop-in DirectDraw DLL replacement that fixes rendering, timing, and input bugs in classic 2D Windows games on Windows 7 through 11.

Whether you're a newcomer or a veteran, DDrawCompat provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Rendering Fix** | Corrects timing and surface blitting issues in old DirectDraw games |
| **Exclusive Mode** | Proper fullscreen exclusive handling for legacy games |
| **Palette Emulation** | Correct 8-bit palette rendering for classic games |
| **No Config** | Drop the DLL alongside the game executable and it just works |
